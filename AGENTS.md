# AGENTS.md

Guidance for AI coding agents of any tool (Claude Code, Codex, Cursor,
Copilot…).

1. Read [`CLAUDE.md`](CLAUDE.md): what ranikust is, the commands, the big
   picture and the rules that can damage the machine. Despite its name it is
   tool-agnostic.
2. Then open [`docs/agents/README.md`](docs/agents/README.md): it routes each
   kind of task to the few short files worth reading. The complete
   must-follow list is [`docs/agents/rules.md`](docs/agents/rules.md).
