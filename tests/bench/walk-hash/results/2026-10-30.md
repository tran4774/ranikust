# Q-038 benchmark results, 2026-10-30

- **Host:** AMD Ryzen 9 9950X3D (16 cores, 32 threads), kernel
  7.0.0-38, ext4 on NVMe; glibc build with mimalloc, `--release`, thin LTO.
- **Root:** `node:22-bookworm-slim` after `pnpm install --frozen-lockfile`
  of `nextjs-kaniko/app` (W1), exported by rootless podman: 265,270
  entries, 245,375 regular files, 15,337 directories, 2,544 MB read by path
  (experiment 09's root: 269k entries, 2,548 MB).
- **Method:** `run.sh <root> <out> 7`: one untimed warm-up walk, then 7
  interleaved rounds of every walker × threads × hash. Page cache warm
  (a user cannot drop caches). Both walkers saw the same entries, bytes and
  checksum. No xattrs read (the same cost for every candidate).
- **Walk:** seconds for one full walk, median (min–max) of 7. `fd`: rayon
  + `openat2` per directory + `getdents64` (`rustix::fs::RawDir`) +
  `statx` with the mount-id guard; `jwalk`: jwalk 0.9.0, `lstat` and
  `open` by path inside `process_read_dir`.
- **Hash in memory:** every file read into memory first, then hashed whole
  (`xxh3_128`, `HighwayHasher::hash128`, `sha2::Sha256`), median of 5.
